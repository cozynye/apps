# Nuni 마스코트 · 감정 5단계

투명 배경 SVG, 1024 캔버스. `entries.mood` 값(1~5)이 그대로 파일 번호다. 구름 색은 `mood-1`~`mood-5` 토큰, 얼굴은 **`mascot-face`(#1f1f24 고정)** — 다크 테마에서도 바꾸지 않는다(다크 구름 위 5.6:1 이상).

| 값 | 파일 | 표정 | 장식 | 라벨(en) |
| --- | --- | --- | --- | --- |
| 1 | `nuni-mood-1.svg` | 안쪽이 올라간 눈썹, 찡그린 입 (슬픔) | 빗방울 3개 (`nuni-primary`) | Rough |
| 2 | `nuni-mood-2.svg` | 일자 입 | 없음 | Low |
| 3 | `nuni-mood-3.svg` | 옅은 미소 | 빛줄기 3개 (`mood-4`) — 4단계의 '해'와 형태로 구분 | Okay |
| 4 | `nuni-mood-4.svg` | 미소 (앱 아이콘과 동일) | 해 + 햇살 | Good |
| 5 | `nuni-mood-5.svg` | 웃는 눈, 벌린 입 | 반짝이 2개 | Great |

**소형 변형 `nuni-mood-N-sm.svg`** — 40pt 이하(캘린더 셀 36pt, 통계 범례 28pt, 위젯)에서 사용. 장식 제거, 얼굴 선 두께 64, 눈 반지름 48. 40pt 초과(감정 선택 시트 52~60pt, 기록 상세, 공유 카드, 온보딩)는 기본 변형.

쓰는 곳: 감정 선택 시트(A4, 기본), 캘린더 셀(A3, sm), 기록 상세(A5, 기본), 통계 범례(A6, sm — 민둥 구름 금지, 반드시 얼굴 있는 sm 변형), 홈 위젯(A12, sm), 공유 카드(A7, 기본). React Native에서는 `react-native-svg`로 넣고 구름 색은 `useTheme().mood[n]`, 얼굴은 `mascotFace`로 주입한다.

인접 단계 명도 차는 1.2~1.9로 작으므로 색만으로 구분하지 않는다: 통계 색 띠에는 `line` 1px 구분선, 범례에는 항상 얼굴 아이콘 + 라벨.
