# 앱 아이콘

Nuni(시안 B: nuni-soft 바탕, 하늘색 구름, mood-4 해)와 Fourpop(시안 B: fourpop-soft 바탕, 코랄 네 컷 스트립, 민트 플래시). 1024×1024 PNG, 모서리는 iOS가 깎으므로 사각형 그대로.

- `*-light.png`: 기본 아이콘. `app.json`의 `ios.icon.light`
- `*-dark.png`: 다크 모드 아이콘. `ios.icon.dark`
- `*-tinted.png`: 틴티드 모드용 그레이스케일. `ios.icon.tinted`

Nuni 구름의 눈·입 위치(y 525 / 592)는 디자인 시스템 README의 마스코트 규칙과 함께 바뀌어야 한다.
