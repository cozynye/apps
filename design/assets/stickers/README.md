# 스티커 — base 팩 22종 (무료, 번들)

512×512 투명 PNG, 선 두께 10/256, 라인 색 `ink` 고정(다크 테마에서도 그대로). 사진 위에 올라가므로 테마와 무관하다.

star · heart · heart-mint · sparkle · bff · love · lol · smile · wink · heart-eyes · crown · flower · cloud · bolt · rainbow · sun · moon · note · cherry · camera · ribbon-today · lollipop

- 꾸미기(B7)에서 스티커는 프레임 canvas 좌표(1200×3600)의 `{x, y, scale, rotation}`로 배치하고, 결과물에 구워진다(MVP는 재편집 불가).
- 기본 크기: 긴 변이 canvas 너비의 22% (264px). 최소 10%, 최대 60%.
- 시즌 스티커팩은 같은 규격으로 CDN `manifest.json`에 `type: "sticker"` 팩을 추가한다.
- 원본 생성 스크립트: `export/stickers.py`.
