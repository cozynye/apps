## 5. Meta 개발자 — Threads 앱 + 토큰 4개


## 9. App Store Connect — 캠페인 토큰 + Admin 키

```
https://appstoreconnect.apple.com 에서
1. 앱 → Fourpop - Photo Booth → 분석(Analytics) → 획득(Acquisition) → 캠페인 → "캠페인 링크 생성"을 열고,
   생성되는 링크에서 pt= 뒤의 숫자(provider token)를 알려줘. 링크는 저장하지 않아도 돼.
2. 사용자 및 액세스 → 통합 → App Store Connect API → 팀 키 → "+" →
   이름 "Marketing Reports", 액세스 "Admin" 으로 생성
3. 키 ID와 Issuer ID를 각각 GitHub Secret ASC_KEY_ID, ASC_ISSUER_ID 로 저장
4. .p8 파일을 다운로드(한 번만 가능)하고, 파일 내용 전체(-----BEGIN PRIVATE KEY----- 포함)를
   GitHub Secret ASC_KEY_P8 로 저장
채팅에는 provider token 숫자와 "저장 완료"만 알려줘.
```
